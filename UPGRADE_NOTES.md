# Course Details Upgrade

Added features:

- Clickable course cards that open a dedicated course details page
- Optional course URL and Continue Learning link
- Progress slider with automatic status updates
- Favorite courses sorted to the top
- Course-specific notes
- Course-specific file attachments stored in IndexedDB
- Responsive light and dark mode styling

## Run

```bash
npm install
npm run lint
npm run dev
```

Uploaded attachments are kept in the current browser on the current device. They are not uploaded to a server and will not transfer between browsers or devices.
