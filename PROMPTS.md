# Prompts Used During Development

## Planning Prompt

Help me plan a React AI Learning Dashboard that tracks AI courses and learning goals.

The application should include:
- Course progress tracking
- Course status filters
- Search
- Learning goals
- localStorage
- Responsive design
- Dark mode
- Accessible keyboard navigation

## Implementation Prompt

Create the React structure and logic for an AI Learning Dashboard using reusable components, form validation, localStorage persistence, search, filters, and responsive styling.

## Testing Prompt

Review the application for:
- Validation issues
- localStorage problems
- Accessibility
- Mobile responsiveness
- ESLint errors

Suggest corrections without changing the main design.
